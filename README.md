## Frequently Asked Questions

**1. Will this work without an internet connection?**
Yes, the core functionality works offline. Internet is only required for downloading models and updates. Once models are downloaded, you can generate images without any connection.

**2. Can I use multiple graphics cards?**
The current version supports primary GPU selection. For multi-GPU setups, you can specify which card to use in the advanced settings. Performance may vary based on your specific hardware configuration.

**3. How do I add my own models?**
Place your `.safetensors` or `.ckpt` model files in the `Models` subfolder within the installation directory. The application will automatically detect and list them after restarting or clicking the refresh button.

**4. What about AMD graphics cards?**
The suite supports DirectML for AMD GPUs. While performance may differ from NVIDIA cards, you can still generate images. Check the performance settings for AMD-specific optimizations.

**5. How do I update to the latest version?**
The application includes an auto-update feature that checks for new versions weekly. You can also manually check via Help > Check for Updates.
